# Harbour Tide icon

Source supplied by the project owner on 2026-10-21:
`harbour-tide-icons.zip`.

The master vector is stored at `misc/harbour-logo.svg`. Package artwork uses
`build/icon.png` and `build/icon.icns`; runtime/tray variants are under
`assets/harbour_mail*.png`.

Palette:

- Tile: `#16233f`
- Envelope: `#4f8cff`
- Tide: `#ff8a5b`
- Flap: `#ffffff`

The icon is the Harbour Mail user-visible brand. The technical
`prospect-mail` identifiers remain unchanged for upgrade and profile
compatibility.
